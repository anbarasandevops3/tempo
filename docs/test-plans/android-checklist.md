# Android checklist

> Only the owner can run these on the phone. Note the phone model and Android version. Any failure in A is P0.

Phone / Android version: ______  Date: ______  APK version: ______

## A. Reliability
- [ ] A1. Start "Run / walk intervals", lock the phone, pocket it: all voice cues, beeps and vibrations arrive on time until "Workout complete".
- [ ] A2. Mid-workout, swipe Tempo away from recent apps: it keeps playing; the notification is still there.
- [ ] A3. Phone call mid-workout: it pauses; after hanging up it continues by itself.
- [ ] A4. Bluetooth headphones: cues play; the headphone play/pause button works; disconnecting them pauses.
- [ ] A5. Battery saver on: the workout still runs to the end.

## B. Notification and lock screen
- [ ] B1. The notification shows the current step, a countdown that ticks, and "Next: …".
- [ ] B2. Back / Pause / Next in the notification work, also from the lock screen.
- [ ] B3. Paused: the notification says "Paused · x left".

## C. Android extras
- [ ] C1. Vibration: long buzz at each step start, short buzz on 3-2-1, triple buzz at the end. Turning "Vibrate" off in the workout stops it.
- [ ] C2. "Dynamic warm-up": the voice says "Leg swings", "Walking lunges"… (the phone's voice).
- [ ] C3. A step with no name still says the type ("Work", "Rest").

## D. Everyday use and data
- [ ] D1. Build a custom workout; the keyboard doesn't cover the field being edited.
- [ ] D2. History shows finished (✓ Done) and stopped workouts with the right times.
- [ ] D3. Export backup on the iPhone (History → Export), import it on Android (⋮ → Import backup): workouts and history appear. And the reverse.
